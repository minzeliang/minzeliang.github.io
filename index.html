🚀 如何部署到 GitHub Pages（免费，四步）
  1. 注册 GitHub → 新建仓库，名字必须叫 你的用户名.github.io（勾 Public）
  2. 把本文件重命名为 index.html，上传到仓库（网页端 "Add file → Upload files" 即可）
  3. 进入 Settings → Pages → Source 选 main 分支 → Save
  4. 等2分钟，访问 https://你的用户名.github.io ——你的作战地图上线了
进阶：每次push自动更新；手机浏览器打开也能打卡（数据在各自浏览器本地）。
